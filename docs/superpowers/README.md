# Historical design records

The files under `specs/` and `plans/` here are **dated design documents written before the work
landed**. They record the reasoning that shaped a feature — the options weighed, the trade-offs taken,
the open questions at the time.

They are **not** authoritative about current behaviour, and they are not maintained as the code moves.
Some describe work that shipped differently, or was later closed deliberately (`claim(ref)`, for
example). Where they and [`../spec/`](../spec/) disagree, `../spec/` wins.

For what the application does today, read [`../spec/`](../spec/) — indexed in
[`../README.md`](../README.md).
