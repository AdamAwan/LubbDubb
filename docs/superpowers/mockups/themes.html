Five theme options

The same overview screen, five times. Nothing here is interactive — scroll to compare. Each palette is six hues plus a ground; every tint on the page is derived from those by color-mix(), so a theme is a token swap.

Warm neutral ground, the harness's own orange, square corners. The only one that speaks the same language as the shared components in styles.css, which are already orange-on-graphite.
