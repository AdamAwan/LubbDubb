The ticket #147 · as it stood at pickup

Public API endpoints can be abused by a single client. We need per-client rate limiting that survives a restart.

  • Limits configurable per route, with a sane default
  • Counters survive a process restart
  • 429 responses carry Retry-After
  • No measurable latency cost on the happy path
